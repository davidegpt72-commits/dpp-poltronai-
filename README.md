# Read.me

This repository contains a static Digital Product Passport (DPP) page for the PoltronAI Relax Pro R1 chair.

## Contents

- `index.html` — the complete product page and styling for the DPP presentation.

## How to view it

Open `index.html` in any modern browser.

## Project summary

The page presents product information including:

- product identity and certification details
- sustainability indicators
- performance and durability requirements
- material information
- lifecycle, maintenance, and repairability notes

This is a lightweight static HTML project with no build step or dependencies.
